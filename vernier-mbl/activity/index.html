오늘의 질문

찬물, 보통 물, 따뜻한 물 중에서 어느 물에 소금과 백반이 더 많이 녹을까요? 그리고 그 물의 온도는 실험하는 동안 정말 그대로일까요?

배울 내용 물의 온도에 따라 용질이 녹는 양이 어떻게 달라지는지 비교해요. 이때 MBL 센서로 물의 온도를 계속 재어, 비교가 공정했는지 자료로 확인해요.

MBL이 뭘까요?MBL

MBL은 센서와 컴퓨터(태블릿)를 연결해, 측정한 값을 바로 그래프로 보면서 저장하고 분석하는 실험 방법이에요. 온도계는 눈금을 눈으로 읽지만, MBL 센서는 온도를 계속 재서 그래프로 보여 줘요.

③ 앱이 그려요그래프와 표가 바로 나타나요

2센서를 태블릿 앱에 연결해요MBL

준비 센서는 쓰기 전에 충전해 두어요. 태블릿에는 Vernier Graphical Analysis 앱(또는 크롬 브라우저의 웹앱)을 열어 둬요.
  1. 센서 켜기: 센서의 전원을 켜면 빨간 불이 깜빡여요. 연결을 기다리는 중이에요.
  2. 앱 열기: 앱에서 Sensor Data Collection(센서 데이터 수집)을 눌러요.
  3. 우리 센서 고르기: 목록에서 센서 몸에 붙은 라벨의 센서 번호(ID)와 같은 것을 골라요. 목록이 안 보이면 WIRELESS를 누르고, 센서를 고른 뒤 Pair를 눌러요.
  4. 연결 확인: 센서의 불이 초록색으로 깜빡이면 연결된 거예요. DONE을 누르면 준비 끝!

3앱 화면 읽는 방법MBL

  1. 1그래프: 가로는 시간, 세로는 온도예요. 선이 오르면 온도가 올라가는 거예요. 센서가 여러 개면 선도 여러 개가 한 그래프에 나타나요.
  2. 2지금 값: 센서가 지금 재고 있는 온도예요. 값이 안정될 때까지 기다린 뒤 읽어요. (물 속에서 저으면 약 20초 안에 거의 맞아요.)
  3. 3수집 시작: 누르면 그래프가 그려지기 시작해요. 다시 누르면 멈춰요. 한 번 더 수집하면 앞의 자료는 저장되고 새 자료가 만들어져요.
  4. 그래프·표: 그래프 대신 숫자 표로도 볼 수 있어요. 도구에서는 가장 높은 값·낮은 값·평균(통계)을 볼 수 있고, 내보내기에서는 그래프 그림(PNG)이나 표 파일(CSV)로 저장할 수 있어요.

※ 설명용 그림이에요. 실제 화면은 앱 버전에 따라 조금 달라요.

센서 연결 순서 (교사 확인용)MBL

  1. 첫 사용 전에 센서를 충전합니다. (제품 설명서: 2시간 이상 / 완전 충전 시 약 24시간 사용)
  2. 센서를 켜면 빨간 불이 깜빡입니다.
  3. 태블릿에서 Graphical Analysis 앱을 열고 Sensor Data Collection을 선택합니다.
  4. 센서 라벨(바코드 근처)의 센서 ID와 같은 센서를 고릅니다. 목록이 안 보이면 WIRELESS를 누르고 센서를 고른 뒤 Pair를 누릅니다.
  5. 연결되면 초록 불이 깜빡입니다. DONE을 누르면 수집 준비가 끝납니다.
  6. 센서가 여러 개일 때는 앱의 센서 정보에서 Identify를 눌러 해당 센서의 불을 깜빡이게 하면 어느 센서인지 알 수 있습니다.

예상 결과와 발문

  • 백반은 물의 온도가 높을수록 더 많이 녹고, 소금은 온도에 따른 차이가 크지 않은 것이 일반적입니다. 숟가락 단위로는 차이가 작게 보일 수 있으니 수업 전에 예비실험을 꼭 해 보세요.
  • 활동 A에서는 따뜻한 물이 시간이 지나며 서서히 식는 곡선이 나옵니다. 컵 재질·양·실내 온도에 따라 내려가는 정도는 달라집니다.
  • 발문 예: “세 컵의 온도 선은 얼마나 떨어져 있나요?”, “숟가락을 넣는 동안 온도는 변했나요?”, “그렇다면 우리 결과를 얼마나 믿을 수 있을까요?”, “온도를 더 오래 유지하려면?”
  • 학생 화면의 ‘3℃ 이상 변하면 안내’ 기준은 제 제안입니다. 학급 상황에 맞게 조정하세요.

안전과 유의

  • 따뜻한 물은 40℃ 안팎으로 교사가 준비하고, 50℃를 넘기지 않습니다.
  • 용질을 맛보거나 입에 넣지 않게 하고, 백반이 눈에 들어가면 바로 씻도록 지도합니다.
  • 센서는 금속 막대 부분만 물에 담그고, 손잡이는 젖지 않게 합니다.
  • 수업 범위: 용해와 온도의 관계를 그래프와 숟가락 수로 비교하는 수준입니다. 용해도 수치, 열량 계산은 다루지 않습니다.
