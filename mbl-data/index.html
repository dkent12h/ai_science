비교 도우미

앱에서 내보낸 CSV를 여러 개 불러와 변화량을 계산하고, 실험이 공정했는지 점검하고, 모둠 결과를 한꺼번에 비교해요.

1자료 불러오기MBL

Graphical Analysis 앱에서 내보내기 → CSV로 저장한 파일을 모둠별로 모아 한꺼번에 선택하세요.

파일은 이 화면에서만 읽고 저장하거나 보내지 않아요. 연습용 예시는 실제로 잰 값이 아니에요.

2변화량을 계산해요MBL

변화량 = 끝 값 − 시작 값 (내려가면 −). 가장 빨리 변한 때는 기록 점을 5개씩 묶어 가장 가파른 곳을 찾았어요.

자료를 불러오면 표가 나타나요.

3공정한 실험이었나요?MBL

비교하려면 바꾸는 것 하나를 뺀 나머지는 같아야 해요. 그래프로 확인해 봐요.

자료를 불러오면 점검 결과가 나타나요.

4모둠 결과를 비교해요MBL

비교할 값:

5주장과 근거를 써요

내 주장: 이(가) 가장 ().

근거(그래프에서 찾은 값)

내 예상과 실제 그래프는?
